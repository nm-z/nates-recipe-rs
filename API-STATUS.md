# Recipe API implementation status

Snapshot: 2026-07-30. `API.ogdl` remains the specification; this file records
the current implementation without narrowing it.

Status: **working** means the public declaration reaches tested execution;
**partial** means only part of the declared family executes; **wrong** means an
executing path changes the declared semantics; **unimplemented** means the
facade records the declaration but no public execution path consumes it.

## Export audience classification

| Surface | Audience | Rule |
|---|---|---|
| `recipe`, `Data`, `Model`, `Train`, `Infer`, metrics, losses, and declaration errors | Recipe script authors | This is the `API.ogdl` facade. It exposes no batch, tile, checkpoint cadence, early-stop, journal, watchdog, or instrumentation controls. |
| `recipe::operations` | operation authors and audits | Normative Recipe operation inventory and checked lowering; not a training-policy surface. |
| `recipe::engine::*` and workspace crates | inter-crate implementers and backend integration | Typed planning, preparation, executor typestate, bounded journals, watchdogs, checkpoint codecs, and debug observers remain available because lifecycle validation and physical realization require them. They are not reinterpreted as user training controls or exported model artifacts. |
| `compile_training`, bounded ingest helpers, and native preparation helpers | integration tests and advanced embedding | Read-only compilation/preparation boundaries. They accept immutable declarations; they do not add user-configurable batching, checkpoint cadence, early stopping, or instrumentation to `Train`. |
| `TrainingReport` | script result | User-visible state is completion, validation availability, and graceful-stop status. Internal execution/checkpoint access is implementation plumbing and must not become a configurable artifact or periodic checkpoint surface. |

The facade compile-fail suite rejects banned methods and hidden defaults, while
the executor/prepare crates retain the lower-level types needed to prove bounded
execution and exact cleanup.
