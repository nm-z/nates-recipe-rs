Column-type detection is a **trained char-level transformer**, not threshold heuristics (which could never return Temporal — see [[project_no_detection_thresholds]]). Now split across crates per [[project_crate_architecture.md]]:

- **Inference (pantry/src/detect.rs):** `predict_kinds(columns)` + `tokenize_column`. Each column → byte stream (`id=byte+1`, PAD=0, vocab≡257, CONTEXT=256) → one row. Runs the embedded `pantry/detector.ogdl` through **recipe-infer directly** (build_layer_params(specs, …, saved, true) → upload → Scratch::new(forward_only) → forward_into → argmax) — NOT via Model/Train (that would cycle pantry→nates-recipe). The spec list is built as `recipe_infer::LayerSpec` values: `[Embed(32,Some(257)), Attn(4), Dense(64,LeakyRelu), Dense(6,Linear)]`.
- **6 classes** (KIND_* consts in pantry/src/detect.rs): 0 Numeric, 1 Temporal, 2 Categorical, 3 Ordinal, 4 Text, 5 Image.
- **Trainer (examples/train_detector.rs — moved here from src/utils/detect.rs, 2026-06-23 Task 7):** `model()` builder = `embed(32).vocab(257) → attn(4) → 64.leak() → 6 → ce, lr(0.002)`. The full labelled corpus lives in this example, NOT the shipped library (training labels don't ship): `SOURCES`/`MARCH`/newchic/stocks consts + `add_new_corpus` (delimiter-aware reader `columns_of(path, Delim, headerless)` for comma/semicolon/tab/space + per-column `kinds`) → `instances()` ×4 prefix augmentation → `build_dataset` → `corpus_split(0xC0FFEE, 0.6)` = 40% train / 60% test. **Writes `pantry/detector.ogdl`** (cwd-relative from repo root).
- **Corpus (2026-06-23):** expanded from the original Kaggle sets with VNA (headerless numeric dumps — the motivating bug) + ~24 UCI datasets in varied delimiters. Wide numeric files (VNA 3204-col predictors, HAR 561) are **column-sampled** so one file can't flood the Numeric class. Empirical: more data > balanced-smaller (v1 1722 rows → 0.918 test; v2 1180 balanced → 0.874). Class balance is logged at startup (`class_balance`).
- Current weights: **train 0.957 / held-out-test 0.934** on the expanded corpus (committed c001692, 20000 epochs). The OLD 0.987 (4be70c4) was the EASIER pre-VNA corpus — not comparable. Functional win: all 3204 VNA predictor columns now classify Numeric (were 1992/3204). 0.934 accepted by user despite the 0.94 target (overfits past ~10k epochs: train climbs, test flattens — don't chase it with epochs, see [[feedback_no_marathon_training_runs]]).

**Retraining gotchas:** (1) `Train::save`/checkpointing only overwrites the ogdl if the new score BEATS the saved one (best-only guard, `recipe_infer::saved_score`) — on a CORPUS CHANGE the old score is incomparable and will block the save, so `std::fs::remove_file("pantry/detector.ogdl")` BEFORE training (keep `.resume_from` so the checkpoint path is still set; it just starts random). For same-corpus continuation use `.resume_from` to warm-start. (2) `include_str!("../detector.ogdl")` (pantry/src/detect.rs) bakes weights at COMPILE time — rebuild after training to ship new weights. See [[project_detector_endstate.md]]. Serialization (dump_ogdl/write_ogdl/saved_score + Param) now lives in recipe-infer (ogdl.rs/enums.rs), not nates-recipe.
