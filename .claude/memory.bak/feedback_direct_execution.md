When the user provides a plan or clear directive, execute it. Don't question scope, don't propose alternatives, don't run brainstorming process on things that are already decided.

**Why:** User is direct and has already done the thinking. Asking "what's your goal" when the goal is obvious wastes time and is frustrating.

**How to apply:** If the user hands you an implementation plan, start implementing. Skip design/brainstorming skills when there's nothing to brainstorm.
